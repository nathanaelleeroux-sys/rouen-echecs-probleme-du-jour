# Rouen Échecs — Problème du jour

Mini-application interactive d'entraînement aux échecs, hébergée indépendamment du site WordPress.

## Fichiers
- `index.html` : page de jeu
- `style.css` : présentation responsive
- `script.js` : échiquier interactif, validation du coup et analyse Stockfish

## Hébergement
Activer GitHub Pages dans Settings → Pages, avec la branche `main` et le dossier `/ (root)`.
